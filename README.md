# Dicte – personlig portefølje

Dette er min egen side.
Her presenterer jeg hvem jeg er, prosjekter jeg har laget, hobbyprosjekter og erfaringene mine.

Nettsiden er laget som et kreativt prosjekt hvor jeg utforsker webdesign, interaksjon og tilgjengelighet.


## Nettsiden inneholder

- Utvalgte programmeringsprosjekter
- Et Pygame-spill som kan kjøres i nettleseren
- Hobbyprosjekter innen blant annet søm og kunst
- Informasjon om meg og bakgrunnen min
- Digital CV og CV som PDF
- Kontaktinformasjon

## Teknologier

- HTML
- CSS
- JavaScript
- Python
- Pygame
- GitHub Pages
- C (skal legges til)

## Space Mayhem

Porteføljen inneholder spillet **Space Mayhem**, som jeg laget med Python og Pygame.
Spillet er bygget om til en nettversjon med Pygbag, slik at det kan spilles direkte i nettleseren uten å installere Python.
